# ТендерКонтур (TMA361)

Веб-платформа отбора строительных тендеров по договору № TMA361 (26.10.2026).

Стек: **Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui**.

Данные и аутентификация — локальный мок (`localStorage`), без внешних API и секретов.

## Запуск

```bash
npm install
npm run dev -- --port 43141 --hostname 127.0.0.1
```

Откройте [http://127.0.0.1:43141](http://127.0.0.1:43141).

Сборка:

```bash
npm run build
npm run start -- --port 43141
```
