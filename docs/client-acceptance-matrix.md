# Матрица требований клиента — TMA361

Сверка кода и доступной конфигурации на 10 ноября 2026 года. Статус «готово» означает, что соответствующий сценарий реализован в продукте; он не заменяет приёмку на реальных данных клиента. «Частично» означает, что экран или базовый сценарий есть, но часть автоматизации, источников или проверки отсутствует.

## Внешние условия, без которых нельзя честно закрыть приёмку

- **Контур.Закупки:** для официальной интеграции нужны оплаченный API-доступ, ключ разработчика и актуальная API-документация. Вход в кабинет по пользовательскому паролю не заменяет API-ключ; кабинет поставщика не менялся.
- **Точность ИИ 97%:** это целевой показатель, а не свойство, которое можно гарантировать настройкой. Для измерения нужны согласованные критерии, репрезентативные документы клиента и размеченные правильные ответы; затем нужен отчёт по precision/recall или согласованной метрике.
- **Северные коэффициенты и экономика:** клиентские тарифы техники и нормо-часы уже загружены; остаются письменные правила Норильска/Ямала, доставки и проживания/вахты, методика накладных/резерва/прибыли, а также прайс материалов.
- **Приёмка интерфейса и Excel:** ссылка на таблицу Егора проверена через подключённый Google Drive: API вернул 404, поиск по ID не нашёл файл. Поэтому вкладки «Ресурсный график» и «Материалы» и контрольный проект с ожидаемыми значениями пока не сверены; нужен доступ к таблице для подключённого аккаунта или экспорт/копия файла.
- **Закрытые площадки:** нужны официальные API-доступы и документация по каждой площадке; без них загрузка закупок оттуда остаётся неподключённой.
